# Conventions de nommage - Max-Morrys

Format recommandé :

`MM_[Canal]_[Format]_[Campagne]_[Angle]_[Version]_[Date]`

## Exemples

- `MM_IG_Carousel_WhatsAppBusiness_GainTemps_V01_2026-06-28.png`
- `MM_YT_Thumbnail_BoutiqueWhatsApp_IA_V02_2026-06-28.jpg`
- `MM_Web_Hero_Formations_Croissance_V01_2026-06-28.webp`
- `MM_Email_Newsletter_IAProductivite_V01_2026-06-28.html`

## Règles

- Toujours utiliser `MM` au début.
- Éviter les espaces et accents dans les noms de fichiers exportés.
- Toujours indiquer la version : V01, V02, V03.
- Toujours indiquer la date ISO : AAAA-MM-JJ.
- Archiver les anciennes versions dans un dossier `Archives`.
