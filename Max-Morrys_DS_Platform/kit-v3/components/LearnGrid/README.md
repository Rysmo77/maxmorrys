Le bloc orange « Ce que tu vas apprendre » : six cases numérotées dans une grille cerclée d'encre (`mm-learn`), sur fond `highlight`.

**Fournir** : exactement six compétences (titre court + une phrase). Pour une fiche de formation, ce sont les compétences validées par une mission.

**Règle** : un seul bloc orange par page. Le texte reste encre, jamais blanc sur orange.

**Mobile** : les cases s'empilent en liste à filets.
