Le haut de page public du Club, en version **aperçu produit clair** : barre de navigation blanche (`mm-lnav`), pastille d'accroche (`mm-pill`), titre net sur deux lignes avec la fin en violet (`em`), promesse en une phrase, deux actions (`mm-btn-club` + `mm-btn-ghost`), mention de prix juste dessous, puis la vraie interface du Fil dans un cadre de navigateur (`mm-browser`) qui se fond vers le bas.

**Fournir** : la promesse, le prix et la phrase « aucun prélèvement automatique ». L'aperçu est le vrai Fil généré par les mêmes composants que l'espace connecté, avec l'étiquette `données d'exemple` juste dessous.

**Règle** : le prix est visible dès le premier écran. Pas de photo plein cadre ni de titre géant sur image : on montre le produit.

**Mobile** : même ordre, actions empilées, l'aperçu passe dans un cadre de téléphone de 320 px.
