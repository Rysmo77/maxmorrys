Le paiement d'une formation en trois étapes (Formation · Paiement · Accès) : choix du moyen (Wave, Orange Money, carte), numéro, récapitulatif avec la remise Club appliquée par le serveur.

**Fournir** : prix servi par le serveur, remise éventuelle et sa raison, moyen choisi, cohorte que la personne pourra rejoindre.

**Règle** : une seule fois, pas d'abonnement ; aucune promesse de remboursement (D-13), les CGV font foi. Le bouton dit le montant exact et le moyen (« Payer 120 000 F avec Wave »).
