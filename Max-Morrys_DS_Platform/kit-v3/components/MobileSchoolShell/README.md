L'espace connecté edu. sur téléphone : en-tête compact (`mm-mtop`) et barre d'onglets flottante (`mm-tabbar`) à cinq entrées : Accueil, Cours, Agenda, Succès, Rysmo.

**Fournir** : l'onglet courant (`aria-current="page"`), le titre de l'écran.

**Règle** : la barre d'onglets est opaque (D-10) et laisse 110 px de marge en bas du contenu.
