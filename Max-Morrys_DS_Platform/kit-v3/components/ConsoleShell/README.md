La console superadmin unique, **en clair** : une barre latérale à libellés groupés avec compteurs (`mm-con__side`), un filtre d'espace (`mm-cspaces`), la recherche ⌘K (`mm-cmdk`), le badge production (`mm-cprod`), quatre tuiles de relevé, la file de ce qui bloque, le journal d'audit et la santé de la production.

**Fournir** : des agrégats serveur **datés** (FR-060) ; le filtre `Tout · Hub · Edu · Club · Conception · Rysmo` filtre tuiles et files ; le badge d'environnement.

**Règle** : pas de courbe sans historique — une tuile sans série temporelle montre un fait daté, pas une courbe décorative. La console répond à « qu'est-ce qui bloque aujourd'hui ».


**Classes v4.3** : `mm-con`, `mm-ccard`, `mm-ckpi`, `mm-ctable`, `mm-st` (ok, warn, stop, info, club, mute), `mm-cbtn` (`is-ink`, `is-club`, `is-stop`), `mm-ctabs`, `mm-clog`, `mm-cfield`, `mm-chk` ; mobile `mm-cm` et `mm-mrow`.
