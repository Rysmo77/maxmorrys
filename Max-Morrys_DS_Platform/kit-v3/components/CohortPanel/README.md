La page Ma cohorte : prochain live de cohorte (compte à rebours, question à l'avance, agenda), répartition des membres par module, missions à relire, mes missions, replays.

**Cohorte** : les personnes qui ont commencé la même formation le même mois. Facultative, désactivée par défaut, on la quitte quand on veut. Seuls les membres qui l'ont rejointe apparaissent (prénom, initiale, module).

**Règle** : jamais de classement individuel. La répartition par module situe sans comparer ; l'orange marque le module de la personne.

**États** : sans replay, le dire (« Le premier live de ta cohorte a lieu samedi »).
