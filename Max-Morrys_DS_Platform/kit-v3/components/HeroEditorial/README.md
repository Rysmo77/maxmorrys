Le héros des pages d'accueil : titre géant en trois lignes, chapô, deux actions, portrait à droite, bande de relevé dessous.

**Fournir** : les trois lignes écrites **par langue** (jamais repliées seules), le chapô (≤ 46 ch), un portrait réel ou l'emplacement `mm-photo` étiqueté (FR-084), deux cartes flottantes portant un fait vérifiable, quatre valeurs de relevé **liées à la base** avec leur source.

**Mouvement** : les lignes montent sous masque, 90 ms entre elles (700 ms) ; puis chapô et boutons en cascade (70 ms) ; les compteurs mono roulent jusqu'à leur valeur réelle (900 ms) ; les cartes flottantes ondulent de 8 px (6 s).

**Ne pas** : sur l'accueil du hub, aucun compteur (FR-122) — la bande de relevé y est remplacée par les deux cartes de piste. Jamais de « 200+ clients » ni de note : une valeur qui ne vient pas de la base ne s'affiche pas.
