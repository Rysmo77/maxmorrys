Les deux colonnes de droite du tableau de bord : l'agenda de la semaine (`mm-days`, `mm-ev`) et les quêtes (`mm-quest`, `mm-qbar`, `mm-claim`).

**Fournir** : les vrais événements (live, quiz, mission, leçon suivante) ; pour chaque quête, l'objectif, le gain en points et l'avancement. « Récupérer » reste désactivé tant que l'objectif n'est pas atteint côté serveur.

**Règle** : les quêtes récompensent la régularité et les missions, jamais le temps passé.
