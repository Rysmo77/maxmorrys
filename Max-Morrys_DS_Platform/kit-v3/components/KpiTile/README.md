La tuile de relevé : libellé, chiffre mono, écart, graphique minimal, source.

**Variantes de graphique** : courbe (`mm-spark`, se dessine en 1,2 s), barres (montent du bas, 18 ms entre elles), jauge (arc qui se remplit).

**Fournir** : la valeur, la série **réelle** si elle existe, et toujours la ligne de source (`mm-kpi__src`). Pas de série : pas de graphique.
