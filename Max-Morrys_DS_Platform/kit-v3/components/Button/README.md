Les actions : bouton pilule de 54 px, avec ou sans pastille-flèche, dans la teinte de l'espace.

**Variantes** : `is-edu`, `is-club`, `is-studio` (dégradés + ombre colorée), `is-highlight` (orange, encre dessus, une fois par écran), encre par défaut, `is-ghost`, `is-quiet`, `disabled` (déclare une promesse non tenue : « Pas encore disponible »). `is-sm` = 40 px. `has-arrow` + `.mm-btn__arrow` = pastille ronde, motif repris des références.

**Mouvement** : appui `scale(.975)` en 120 ms ; au survol desktop la flèche glisse et pivote de −45°, un reflet traverse le dégradé une fois (700 ms). `mm-iconbtn` : 44 px, appui `.94`, pastille rouge `is-live` qui pulse pour une notification non lue.

**Ne pas** mettre deux boutons dégradés côte à côte, ni de texte blanc sur `highlight`.
