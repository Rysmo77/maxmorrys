Ce que l'adhésion ouvre, puis comment on commence.

- `mm-offer` : grille de six cartes (`mm-offer__c`), une icône teintée, un titre, une phrase. Toutes les promesses sont **garanties aujourd'hui**.
- `mm-build` : un bandeau en pointillés juste dessous pour ce qui est **en construction** (replays, digest, cercles ouverts par les membres).
- `mm-steps` : trois étapes (`mm-step`) avec une petite vignette d'interface au-dessus (moyens de paiement, cercles, première publication).

**Règle** : rien en construction ne se glisse dans les six cartes. Sur mobile, les cartes passent en ligne (icône à gauche) pour rester courtes.
