La salle du live de cohorte : scène vidéo avec écran partagé, badge « En direct », barre avec le mode audio seul et son débit, file de questions votées.

**Fournir** : le débit réel de chaque mode (vidéo 360p, audio seul), les questions et leurs votes, ce qui est partagé à l'écran.

**Règle** : tout travail d'apprenant montré en direct l'est avec son accord, et c'est écrit à l'écran. Le replay reste 30 jours, dans la cohorte seulement.
