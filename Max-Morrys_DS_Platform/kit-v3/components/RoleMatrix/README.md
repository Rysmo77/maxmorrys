La matrice des rôles : six rôles × permissions, lisible d'un coup d'œil.

**Rôles** : Superadmin, Admin Edu, Admin Club, Modération Club, Admin Conception, Support. Détail dans la section Console superadmin.

**Règle** : un rôle s'accorde par le serveur seulement, avec motif, et s'écrit au journal (corrige FR-267 / R-38).


**v4.3** : lignes ajoutées pour les cohortes, lives et relectures (Admin Edu), le classement et le parrainage (Admin Club), les opportunités (Modération). Légende en toutes lettres : écrit, lecture seule (« lu »), aucun accès.
