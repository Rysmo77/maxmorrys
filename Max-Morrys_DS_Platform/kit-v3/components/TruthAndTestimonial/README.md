L'encart de vérité et le témoignage, qui remplacent la preuve sociale inventée des références.

**Encart de vérité** : deux colonnes « Ce que je peux te prouver » / « Ce que je n'affiche pas », bordure pointillée. Obligatoire sur chaque écran de vente.

**Témoignage** : n'existe que s'il vient d'un apprenant **certifié** et modéré (FR-029) ; il porte le code du certificat en mono. Sinon, l'état vide le dit.

**Ne pas** reprendre les carrousels d'avis, les étoiles ni les logos de partenaires des références sans accord écrit.
