La méthode en quatre étapes : un accordéon dont l'étape ouverte devient une carte d'encre.

**Fournir** : 3 à 5 étapes, un emplacement visuel à droite. Une seule étape ouverte à la fois.

**Mouvement** : le + pivote en ×, la carte passe à l'encre (220 ms), le corps entre en glissant (380 ms). La hauteur n'est pas animée : la liste se réorganise, son contenu arrive.
