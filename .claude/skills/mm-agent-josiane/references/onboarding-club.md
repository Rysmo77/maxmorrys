# Onboarding du Club (J0-J30)

**Réussite :** un parcours qui fait vivre au nouveau membre trois moments de valeur avant J+30.

## Démarche
1. Lister ce que le membre reçoit vraiment (`src/i18n/locales/fr/club.json`, `src/lib/club/pricing.ts`) : fil, messages, agenda, 2 sessions en direct par mois, −20 % sur les formations, 5 questions Rysmo par jour, annuaire.
2. Définir les moments de valeur (ex. première question posée, première session suivie, première présentation dans le fil).
3. Séquence : J0 bienvenue, J1 se présenter, J3 première question à Rysmo, prochaine session, J14 bilan, J30 point d'étape. Canal par étape : e-mail (Cloudflare) ou WhatsApp (opt-in).
4. Rédiger les messages (tutoiement, un CTA chacun) ; briefer Serge pour l'automatisation.
5. Indicateurs : activation à J+7, J+30.
