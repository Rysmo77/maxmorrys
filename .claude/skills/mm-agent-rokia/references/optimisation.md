# Optimiser un article existant

**Réussite :** une liste de modifications précises qui augmente les chances de l'article d'être affiché, cliqué et cité, sans en trahir le fond.

## Démarche
1. Données : impressions, position, requêtes de la page (Search Console, export de Max) ; statut d'indexation.
2. Titre SEO ≤ 47 caractères et `metaDescription` ≤ 155 qui donnent envie de cliquer sur la requête réelle.
3. Introduction : réponse directe dans les deux premières phrases (utile aux moteurs génératifs).
4. Intertitres alignés sur les questions réelles ; FAQ ; définitions claires ; entités nommées précises.
5. Sources primaires citées (un chiffre sans source se retire).
6. Maillage vers le pilier et l'offre ; liens depuis d'autres articles vers celui-ci.
7. Hors charte à retirer au passage : H1 dans le corps, emojis, vouvoiement, CTA de fin, année dans le titre si le contenu est durable.

## Livrable
`_bmad-output/editorial/<slug>/optimisation.md` (liste de modifications), à exécuter par Cheikh puis via l'admin.
