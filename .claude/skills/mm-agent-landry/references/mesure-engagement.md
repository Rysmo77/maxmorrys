# Mesure et engagement mobile

**Réussite :** un plan de mesure respectueux (sans pistage tiers) et un calendrier de messages utiles.

## Démarche
1. Mesure : statistiques natives des stores (impressions, conversion de fiche, installations, désinstallations), UTM sur les liens web vers les stores (avec Yann), événements produit essentiels.
2. Push / in-app : 3 à 5 messages déclenchés par l'usage (leçon non terminée, nouvelle leçon, quota Rysmo rechargé), heures de Dakar, plafond hebdomadaire, consentement.
3. Rédaction : tutoiement, un message = une action.
