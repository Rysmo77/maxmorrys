# Dossier de sources pour un sujet

**Réussite :** Cheikh peut écrire l'article sans jamais inventer : chaque chiffre, exemple et citation dont il aura besoin est déjà là, sourcé.

## Démarche
1. Lister les questions auxquelles l'article doit répondre (depuis le brief de Rokia ou la demande d'Aminata).
2. Chercher pour chacune une source primaire (recherche web, documents officiels, centres d'aide des plateformes). Lire la source elle-même, pas un résumé.
3. Consigner chaque élément : affirmation, citation exacte, URL, éditeur, date de publication, date de consultation, fiabilité (primaire / secondaire / à éviter).
4. Pour les exemples locaux : préférer des cas publics et sourcés ; sinon, les marquer « exemple hypothétique » pour que Cheikh les présente comme tels.
5. Signaler les trous : ce qu'on ne peut pas affirmer faute de source.

## Livrable
`_bmad-output/editorial/<slug>/sources.md` (tableau des faits + section « Non trouvé / ne pas affirmer »).
