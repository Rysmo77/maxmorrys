Le chemin de l'argent, cliquable Accueil → catalogue → fiche → paiement → attente → succès → mon espace → lecteur → certificat. Tout se déclenche sur l'élément réel : la carte « Je te forme », le bouton « Crée ton compte », « Je m'inscris », « Payer », « J'ai payé, vérifie », « Ouvrir la première leçon ». Les flèches de retour reviennent. Glissement 260 ms pour les détails · retour inversé · feuille montante 300 ms pour le paiement · fondu croisé 180 ms pour la barre d'onglets · maillage persistant, fondu de 500 ms au changement de territoire.
